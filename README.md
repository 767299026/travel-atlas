# 迹屿 · 旅行记录与路线知识库

面向中国国内旅行与徒步，长期维护路线资料、行程规划、路线补绘和图文日记，并逐步加入基于个人资料的 AI 问答。

当前阶段：已完成 M0–M3、M4.1 和原型主要页面建设，支持行程、实际记录、到访、私密图文、独立管理端，以及地图选点、手工补绘、GPX、社区户外地图与区域徒步候选。当前已提供域名预览及可撤销行程分享；正式运行／整体恢复、思源导入与 AI 后续加入，正式上线验收尚未完成。

从 [文档索引](docs/README.md) 进入设计与技术资料；用户确认的选择和待验证建议见 [决策记录](docs/decisions.md)。最近整理：2026-10-23。

## 已确定技术方向

- 前端：Vue 3 + Vite + TypeScript，优先适配手机浏览器。
- 后端：Node.js + TypeScript，提供独立业务 API。
- 数据库：复用本机 MySQL，使用专属数据库和账号。
- 客户端：先做网站，预留 Capacitor 安卓打包。
- 核心使用场景：出发前在线规划、回来后图文记录，无离线地图需求。
- 管理端：独立 Web 页面，承担用户、资料与服务配置管理。

后端采用 Fastify + TypeBox、Drizzle + mysql2；图片暂存本机私有目录，Sharp 生成衍生图。高德底图与官方显示转换已接入，户外模式采用 Leaflet／OpenHikingMap，区域徒步采用本机 BRouter 1.7.10；供应商数据长期使用条件、对象存储及 AI 仍按阶段验证，依据见 [技术方案](docs/technical-plan.md)。

## 目录

- `frontend/`：Vue 网页、复用原型样式与手机适配。
- `admin/`：独立 Vue 管理端，账号、概览与审计。
- `backend/`：Fastify API、身份、MySQL 仓库与迁移；思源和 AI 后续加入。
- `docs/`：产品、原型、提示词、技术选型、数据源、验证计划和决策记录。
- `packages/contracts/`：共享类型与路线命令规则。
- `scripts/`：本机开发与浏览器验证。
- `.env`：本机私密配置，禁止提交；变量说明见 `.env.example`。

前后端使用同一仓库。前端构建为静态资源，由反向代理提供访问；后端作为独立服务运行。

使用端与管理端独立构建，共用业务后端；后台接口要求管理员权限。

## 配置

本机 `.env` 保存思源、高德、MySQL 与网站登录配置，权限为 `600`，由后端加载，不进入前端构建包。高德 JS Key 按官方 SDK 要求在登录后的运行时提供给浏览器；安全密钥和 WebService Key 保留服务端。新环境复制 `.env.example` 并填写值。

2026-10-23 已先备份再完成原型页面完善增量迁移，当前 19 张业务表和迁移账本，保留本人账号；隔离测试表已清理。本轮按用户要求另行备份后插入 3 个标明「演示」的行程及图文，用于地图审核；模拟内容可按清单清理，见 [地图迭代](docs/map-iterations.md)。初始网站账号见 `.env` 的 `ADMIN_USERNAME`／`ADMIN_PASSWORD`，与数据库密码独立；管理端重置密码不会回写该初始配置。

```bash
npm ci
npm run db:migrate
npm run user:init
npm run dev
```

默认 Vue 为 `http://127.0.0.1:5178`，API 为 `http://127.0.0.1:3080`；构建使用 `npm run build`，静态资源在 `frontend/dist`，可交给 Nginx。当前没有修改既有 OpenResty 配置，不需要安卓包。

## 数据原则

- 路线模板、出行计划、实际出行和日记分别建模。
- GPS 实录、导入参考、路网规划、手工补绘均保留来源，展示时明确区分。
- 初期只读取指定思源文档及其子文档，导入内容默认私有。
- 原始笔记、提取结果和人工修订分开保存，避免同步覆盖修改。
- 秘钥仅后端使用；公开分享不能间接暴露思源私密资料。
