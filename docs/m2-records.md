# M2：实际记录、图文日记与独立管理端

更新：2026-10-22。状态：**本机实现、隔离验证与构建版预览升级完成；真实手机照片与正式上线验收待补充**。承接 [实施清单](implementation-plan.md) 的 M2，不包含 M3 地图算路与 M4 分享。

## 本轮交付

1. 计划与实际独立编辑。支持创建空实际记录、复制全部或选中日期；复制前展示影响，已有实际内容明确选择追加／替换。新对象使用独立 ID 并保留复制来源版本。
2. 到访是用户主动确认的独立记录。完成旅程、复制路线均不自动增加到访；移除地点或替换实际路线时保留已确认地点快照。
3. 私密日记支持独立记录或关联行程／日期／地点；正文与有序照片说明、保存版本与草稿、阅读和删除。关联对象失效时保留名称快照并提示。
4. 图片先使用本机私有存储，保存原图、去除元数据的阅读图与缩略图；原图仅本人鉴权下载。限制上传大小、像素、数量、并发和个人配额。存储接口便于后续迁移对象存储；文件路径不通过静态站点暴露。
5. 管理端独立目录、独立构建与入口；最小范围是数据概览、用户创建／停用／角色与密码重置、必要操作审计。使用端不增加后台导航。

## 实现约定

- 日期使用本地日历字符串，照片时间不解释为完整运动时间；复制记录不称为 GPS 实录。
- 到访与日记关联保留快照；历史到访不会随着新的同名 stop 自动重绑定。
- 日记先采用纯文本段落与有序照片，不渲染用户 HTML；不生成可公开访问的分享链接。
- 图片上传与日记保存分开：上传成功仅说明图片已私密保存，日记保存后才关联。放弃编辑不会显示为已发布；未关联图片可通过维护命令按保留期清理。
- 初选常见 JPG／PNG／WebP；其他格式按用户样本与运行时解码能力确认。没有可解码原图时返回明确错误，不伪装上传成功。
- 当前服务器剩余磁盘约 9.3GiB（2026-10-22 快照），默认个人媒体配额 1GiB，可在后端配置；新增原图与衍生图全部计入。
- M2 增量迁移保留 M1 表和数据。先完成隔离 API／浏览器验证，再备份业务数据并升级；继续使用 screen，不修改原始 OpenDesign。

## 验收重点

计划／实际互不覆盖；复制并发与重试；替换后到访／日记快照保留；独立日记与关联校验；保存冲突不丢草稿；图片 MIME／真实解码与限制、元数据去除、越权访问／删除拒绝；账号停用／密码重置撤销会话，最后一个管理员不能被降权或停用；主站与管理端独立构建及手机尺寸检查。

## 当前页面与操作

- 主站导航为「旅程／回忆／我的」。旅程详情可在计划和实际之间切换；概览提供复制，尚无实际记录时也可从空记录开始。
- 实际地点菜单可确认到访、取消到访或写日记。「我的」展示真实统计和最多 500 条近期到访，历史地点被移除时明确提示快照保留。
- 「回忆」分页读取本人日记；编辑页可关联旅程／计划或实际／某天／地点，也可完全独立记录。支持逐张上传、说明、排序、移除、保存草稿和保存记录。两种状态均为私密。
- 阅读页按纯文本段落和照片顺序显示，不解释 HTML；点击原图触发本人鉴权下载。无分享链接，不从照片 GPS 自动生成足迹。
- 编辑草稿按账号、日记或新建页面、标签页保存。网络失败可重试，409 保留本地内容并支持下载 JSON；不会自动合并。新浏览器／新标签页不保证恢复其他标签页草稿。
- 管理端位于 `admin/`，独立构建，回环端口 5179；支持概览、用户创建、停用／角色、重置密码和最近 50 条审计。普通编辑账号无后台权限；停用、改变角色或重置密码会撤销该账号的会话。系统保留至少一个启用的管理员。

## 图片边界与维护

| 项目 | 当前实现 |
| --- | --- |
| 格式 | 静态 JPG／PNG／WebP；不支持 SVG、动图和 HEIC |
| 单张上传 | 默认 20MiB，真实解码，最多 5000 万像素 |
| 单篇照片 | 最多 24 张；逐张上传，可失败重试 |
| 阅读与缩略图 | WebP，最长边分别 2048／480；按 EXIF 旋转并移除元数据 |
| 原图 | 保留上传原始字节和元数据，只能本人鉴权下载 |
| 资源 | 每个 API 进程同时处理 1 张，Sharp 并发 1、缓存 32MiB；个人原图及衍生图默认合计 1GiB，磁盘预留 512MiB |
| 存放 | `MEDIA_ROOT` 默认 `data/media`，私有目录 700／文件 600；不映射到 Nginx 静态根 |
| 删除 | 日记保存移除照片或删除日记后，该媒体立即不可读；文件删除失败由清理命令补偿 |
| 放弃的上传 | 未关联文件不会出现在日记，`npm run media:cleanup` 清理超过 7 天的未关联媒体与遗留文件；当前未设置定时任务 |

`MEDIA_QUOTA_BYTES`／`UPLOAD_MAX_BYTES` 可在 `.env` 调整；超过上传限额仍受反代配置限制。当前 OpenResty 全局上限已为 50m，本轮无需修改。单张照片只能关联一篇日记；需要重复使用时重新上传。草稿超过 7 天的未关联图片若已清理，需要重新选择照片。

`npm run db:backup` 使用私有临时选项文件执行 `mysqldump`，输出 `data/backups/*.sql`、权限 600；不包含照片。完整备份还需同步 `MEDIA_ROOT` 与安全保存配置。**当前仅完成升级前数据库备份，尚未演练数据库与媒体整体恢复，也未配置自动备份。**

## 当前接口

均在 `/api/v1` 下，要求登录；写操作沿用 Origin／CSRF。完整请求字段见 `packages/contracts/src/records.ts` 和 `backend/src/record-schemas.ts`，复制和日记写入采用幂等标识，编辑／删除检查基础版本。

| 方法与路径 | 用途 |
| --- | --- |
| `POST /journeys/:id/actual-copy-previews` | 检查计划／实际版本与所选日期，只读影响预览 |
| `POST /journeys/:id/actual-copy` | 追加或替换实际，保留来源、新 ID 和快照 |
| `POST /journeys/:id/actual` | 从空实际记录开始 |
| `GET /visits?journeyId=` | 本人近期到访，最多 500 条 |
| `POST /routes/:id/stops/:stopId/visit` | 主动确认实际地点到访 |
| `DELETE /visits/:id` | 取消一条到访，不修改行程状态 |
| `GET /me/summary` | 真实旅程、日记、到访、图片用量 |
| `GET /diaries?journeyId=&cursor=` | 私密日记每页 20 篇 |
| `POST /diaries`、`GET/PUT/DELETE /diaries/:id` | 新建、阅读、版本保存与删除 |
| `GET /media/capabilities` | 当前可用格式、大小、像素、篇数和配额 |
| `POST /media` | multipart 单文件，`X-Upload-Id` 标识重试 |
| `GET /media/:id/content?variant=original/preview/thumb` | 本人私有图片；原图 attachment |
| `DELETE /media/:id` | 移除本人未关联图片 |
| `GET /admin/overview`、`GET /admin/users?cursor=` | 管理员概览与账号分页（50 条） |
| `POST /admin/users`、`PATCH /admin/users/:id` | 创建与版本化调整账号 |
| `POST /admin/users/:id/password` | 版本化重置密码并撤销全部会话 |
| `GET /admin/audit` | 最近 50 条管理操作，不包含密码正文 |

管理账号操作用用户名唯一约束或 `baseVersion` 避免重复和覆盖，不把密码请求正文／哈希写进通用幂等记录。媒体原图不走静态目录，响应禁止缓存；停用或撤销会话后无法重新读取。
