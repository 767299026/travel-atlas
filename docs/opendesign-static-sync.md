# 当前网页反向同步至 OpenDesign

2026-10-27：用户要求把当前网页的页面与样式更新到原 OpenDesign 原型，允许省略业务逻辑。本轮明确授权覆盖原型入口，原型后续仍默认由用户设计维护。

## 同步方式与范围

- 从当前 Vue 网页渲染结果导出独立 HTML，沿用真实 class、图标、表单、布局和可读 CSS；不把压缩后的 Vue 构建包当作原型源码。
- 四个入口及其主要状态：国内／世界／省级地图、时光／寻找、城市概览与旅程／地点摘要、聚合与重合候选；旅程列表、新建、概览、每日、实际、地点与信息表单、路线地图；图文列表、阅读、编辑、新建；个人、心愿、设置、分享范围与预览。
- 页面目录独立为 `prototype-index.html`，默认 `index.html` 仍打开足迹。根目录 HTML 可在 OpenDesign 中逐页设计；`current/styles/` 为当前样式，`current/prototype.js` 仅提供预览跳转和反馈。
- 使用随机前缀测试表与独立浏览器上下文创建演示内容，不读取／导出本人行程、私密照片、认证会话或运行配置。退出清理本轮测试资料。交付前复核 11 类既有业务表的条数和 SHA-256 指纹，与同步前一致。
- 地区地图为本地静态预览；城市底图为可编辑 SVG 示意并标注非导航。无需高德 Key 或业务 API，地图和保存／分享不具备正式业务行为。
- 示例摄影复用原型已有素材，来源与限制保留在 `assets/SOURCES.md`，不表示本人实拍，也不进入旅行项目 GitHub 仓库。

## 执行步骤

1. 通过 OpenDesign 项目 API 与项目 ID 定位原型，不将运行时数据目录当成固定接口。
2. 导出到 Git 忽略的本机工作目录，检查页面、相对链接与响应式布局。
3. 备份原入口、说明与既有设计源码；检查原型入口在导出期间未被其他编辑修改。
4. 同步静态页面与共用样式，保留原 v4 脚本与素材；入口切换到当前静态预览。
5. 在真实 OpenDesign 预览路由复查，两轮截图自审并记录结果。

导出脚本：`scripts/export-opendesign.ts`。需现有构建、浏览器测试依赖、本机测试库连接及运行中的 OpenDesign。可通过 `OPENDESIGN_URL`、`OPENDESIGN_PROJECT_ID`、`PROTOTYPE_OUTPUT` 指定实例、项目与输出位置。运行时读取的密钥不写入导出包。

恢复原 v4 的方式：先通过项目 API 重新确认工程位置，再从该备份恢复 `index.html`、`DESIGN.md`、`index.html.artifact.json`。旧脚本、样式和素材未被移除，恢复旧入口后即可重新运行旧原型；无需删除新导出的页面。恢复或再次同步前先保留后来在 OpenDesign 中的新设计。

后续显式同步可运行 `npm run prototype:export`。用普通静态服务器或 `file://` 打开导出目录，配置 `PROTOTYPE_REVIEW_URL` 后运行 `npm run prototype:review`；实际看完截图再执行 `npm run prototype:install`。安装校验本轮检查与导出时间一致，并比对原型入口摘要，避免覆盖导出期间另行修改的入口；它不是自动双向合并。默认浏览器依赖、`PLAYWRIGHT_MODULE`／`CHROME_PATH` 沿用现有浏览器验证方式。
