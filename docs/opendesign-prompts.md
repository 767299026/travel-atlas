# OpenDesign 提示词归档

整理：2026-10-21。以下为对话提示词的整理版，保留设计意图与验收流程，非逐字聊天备份。当前规范见 [原型设计](prototype-design.md)，后续修改以当前需求为准，不机械重放历史提示词。

## 使用约定

助手默认只读查看用户的「迹屿 足迹地图设计」项目，给出完整可复制提示词，由用户在 OpenDesign 操作与预览。页面设计不能直接替代真实地图、后端、账号权限或 AI 能力验证。

使用端与管理端分别设计。后续如果制作管理端，应新建独立原型／页面；当前未归档已制作的管理端提示词或结果。

## v2：补齐规划、日记和资料流程

```text
请基于当前「迹屿 Travel Atlas」原型完善使用端，保留现有品牌、暖纸白／森林绿／陶土橙、地图首页和已有交互，提供可交互手机预览。

产品主要面向中国国内旅行与徒步：出发前选路线、安排行程，回来后写图文日记、补充实际路线并分享。不要求离线地图，不依赖持续 GPS 记录。

保留底部地图、旅程、回忆、我的四个入口。

地图区分已去过与想去，计划不计入到访。城市详情可查看记忆或发起计划。
旅程增加计划中／已完成、新建行程、自行创建或从路线资料开始。
路线资料支持地区、月份、天数、玩法和强度筛选，详情有季节、天数、地点、难度、来源及核验日期，缺失字段留空。
行程详情支持总览／每日安排／日记；每日地点可添加、编辑、删除、排序，交通接驳与徒步分段表达。
计划路线与回程补绘分别保留；示意线明确标注，不生成没有数据支持的实际里程、耗时、速度或爬升。
完成计划只改变状态，不自动新增日记、照片或到访。
回忆提供日记列表、完整阅读、标题／日期／正文／地点编辑、照片增删与说明，关联行程及某一天，也支持独立日记和草稿。
分享设计私密／持链接可见／公开和访客预览。持链接可见说明任何拿到链接者都能访问。原型不生成真实链接，访客隐藏编辑、个人事项与私密内容。
规划内预留帮我安排，输入月份、天数、出发地、兴趣与强度；结果标记演示并列来源，用户确认后加入。
我的仅含个人资料、统计、心愿、个人设置。用户管理、角色、数据管理、思源同步、AI 配置归未来独立 Web 管理端。

做通资料 → 新建 → 分日安排 → 保存 → 完成 → 日记 → 分享预览。
按钮有明确结果，表单校验，草稿保留，离开未保存有提示，补充空状态。
示例摄影不描述为用户实拍，演示数据跨页面一致；不接真实数据库、思源、地图规划或 AI。
```

结果与遗留：v2 补上主要业务界面，但存在单城市限制、详情占位重、主要操作不聚焦、缺字段筛选为空等问题，进入 v3。

## v3：跨城市及规划体验

```text
基于迹屿 v2 优化真实旅行规划流程，保持品牌和已有地图、日记、草稿、分享能力。不增加管理端或真实服务。

1. 支持跨城市、多地区行程。分别保存出发地、途经目的地、每日地区与选填住宿。地点可属于不同地区，未知地区允许手填并标待定位。
保留武汉两日示例，新增明确标注演示的跨城多日行程，覆盖交通接驳、城市漫步与徒步，不编造精确里程、耗时、票价和开放状态。

2. 每日地点列表为主要编辑区域，路线示意为辅助。支持添加、编辑、排序、删除、移到另一天，地点带到达方式、选填时间和备注。
计划与实际独立。提供复制当天计划为实际记录的主动操作；已有内容时明确追加或替换，不静默覆盖，不自动确认到访或新增日记。

3. 详情与编辑使用紧凑顶部，缩小重复品牌。390×844 及窄屏优先展示安排，路线可折叠，返回、滚动和安全区清楚。

4. 按场景设置主要操作：计划突出继续安排，有修改突出保存，完成后突出写日记／补实际。标记完成是次要操作；同页只保留一个帮我安排入口。

5. 缺少季节、天数、强度不等于不匹配。区分符合条件和条件不完整资料，允许主动查看；也可隐藏暂时缺乏数据的筛选项。不要编造字段。列表重看点、地区、节点，来源放详情。

验证跨城市创建 → 分日添加 → 排序 → 跨日移动 → 保存 → 完成 → 复制并修订实际 → 日记 → 访客预览。
回归返回、草稿、空状态与未保存提示，访客仍不含私人事项和私密关联内容。
```

结果与遗留：v3 解决跨地区、复制实际、空间和筛选问题；地点操作区仍重，添加入口同屏重复，进入 v4。

## v4：界面收尾

```text
请基于迹屿 v3 做一次界面收尾，保持现有功能、数据和页面结构。

1. 每日安排中，“添加地点”同时出现在列表末尾和固定底部，请根据滚动状态合理保留入口，减少同屏重复。
2. 地点卡片目前常驻上移、下移、跨日移动、编辑、删除五个按钮。请降低操作区的视觉重量，例如保留编辑和“更多”，将次要操作放入有文字说明的菜单。保持操作容易发现。
3. 检查长行程名称、长地点名称、较多天数、空地点列表及键盘弹出时的布局，确保内容和主要按钮不被遮挡。
4. 回归跨日移动、草稿保存、计划复制为实际记录、日记及分享预览，保留已有行为。

不新增业务功能，不加入后台管理，继续提供可交互预览。
```

结果：用户反馈完成 v4；助手抽查重复入口、菜单排序与跨日、保存恢复、窄屏及缩小视区表单，建议作为使用端开发基线。具体验证范围见 [原型设计](prototype-design.md)，未接入服务的能力仍待正式实现。
