## 3. 四个入口与主要页面

| 入口 | 页面与功能 |
| --- | --- |
| 地图 | 中国／世界、国家→省→城市、年份、城市记忆抽屉、已去过／想去、发起计划 |
| 旅程 | 计划中／已完成、资料入口、新建、多目的地、详情总览／每日安排／日记、分享 |
| 回忆 | 按时间的日记、阅读、创建与编辑、关联行程／某天／地点、照片与说明 |
| 我的 | 个人资料、足迹统计、心愿、个人设置；不放后台数据或用户管理 |

### 路线资料

地区、玩法为主要筛选，月份／天数／强度按需展开。已知不匹配排除，缺少条件进入“条件尚不完整”分组，允许主动查看。资料来源和核验详情放到详细页，缺值不编造。

### 行程

分别记录出发地、途经目的地、每天地区和可选住宿。地点可跨城市，拥有到达方式、选填时间与备注。未知地名可手填，明确待定位。

每日地点列表优先；日期横向滚动，选中日期保持可见；路线是默认折叠的辅助示意。地点支持排序、跨日移动、编辑和删除。常驻“编辑／更多”，更多提供有文字的操作及禁用说明，删除需确认。

未修改的计划突出“继续安排／添加地点”，有修改时保留“保存修改”，完成后突出“写日记／补充实际记录”。行程选项中提供助手、信息编辑与标记完成。同一时刻按滚动状态减少重复添加入口。

### 草稿与实际记录

编辑切换保留草稿，离开时提供继续编辑、保留草稿离开、放弃修改。复制计划到实际需要主动确认，已有内容选择追加或替换；复制后独立编辑。复制和完成不产生自动到访。

### 日记与分享

日记可独立或关联行程与某一天，支持标题、日期、正文、地点、照片添加／移除／说明。示例摄影不能描述为用户实拍。

私密、持链接可见、公开分别设置。原型只保存本机偏好和预览，不产生真实可访问链接或声称有服务端权限。访客不显示编辑、个人导航、私人准备事项或私密关联日记；封面也不能取自私密内容。

### AI

规划内提供“帮我安排”，演示输入偏好、引用与可确认草稿；不新增底部入口。未连接真实模型时明确标注演示；确认追加，不静默覆盖现有地点。

## 5. 已执行的评审验证

助手在独立 Chrome 浏览器上下文中操作，测试数据不写入用户已有浏览器数据或原型源文件。

- v2：抽查旅程、每日安排、资料筛选、回忆及个人页，发现月份筛选为空等问题；抽查无脚本错误。
- v3：地点跨日移动、复制实际、再次复制提示、删除实际不影响计划、保存与刷新、条件不完整资料分组；390px 和 375px 部分页面检查，无所测脚本错误及文档横向溢出。
- v4：确认同屏重复添加减少；更多菜单首尾移动禁用说明、排序、跨日移动、保存；长地点名在 320px 未导致文档／地点列表横向溢出，刷新后修改仍在。375×480 缩小视区中地点保存按钮在可视范围。

以上是抽查，不是全量回归。键盘只做浏览器缩小视区模拟，尚未安卓真机或微信内置浏览器验证。原型自身 DESIGN.md 还有其生成过程的验证描述，本文不把那些描述全部视为助手独立复验。

## 6. 实现时保留的边界

原型数据含模拟旅程和公开来源参考摄影，不能直接作为个人实际数据或生产授权素材。路线目前是访问顺序示意，不是真实算路。IndexedDB 是本机原型存储，不是服务器持久化。分享与 AI 是界面演示，正式权限和服务接入需另行实现验证。

管理端原型、真实地图覆盖、同步审核、API、数据库、媒体权限及安卓适配见其他文档，不能以原型通过替代这些验证。
