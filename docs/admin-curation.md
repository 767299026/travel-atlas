# 后台资料整理 · 第一批

日期：2026-10-31。用户明确目前测试阶段，先完善后台管理，运行保障后置。本轮承接 [管理工作台](admin-console.md)，实现待整理入口、状态筛选、照片预览／单张编辑及对应使用端入口；不实施 TLS、定时备份或服务自动恢复。

## 使用流程

- 概览的「待补精确位置」「待补日期」「待补城市」直接进入相应筛选清单，数字与清单使用同一条件。
- 内容台账按资料类型显示状态筛选；可组合关键词、翻页，URL 保存类型、状态、关键词和页码，刷新可恢复；空结果可重置筛选。
- 照片显示真实缩略图、拍摄日期和存储摘要。点击缩略图、名称或「查看」打开整理弹窗。
- 弹窗提供完整比例的受控预览、日期、简短备注和拍摄地点。地点通过高德名称搜索选择，不要求经纬度，也不要求在地图上盲点；可只记名称，仍标记待补精确位置。
- 原图中有日期／位置时提供主动采用入口，原图元数据不自动当成用户确认；清除地点也需要显式保存。
- 保存成功后重新查询当前清单：补齐日期的照片会退出「待补日期」，定位完成后会退出「待补精确位置」。修改照片信息不会新增到访、生成轨迹或修改旧日记正文／图片说明。
- 本人旅程、图文日记和旅程到访详情提供使用端编辑入口。主站与管理域名分别使用会话；使用端未登录时仍需登录，不传递会话凭证。其他账号不展示会越权或打开错误内容的本人编辑入口。

首批支持单张照片编辑，批量改日期／位置后续单独实现；未增加内容批量删除、跨账号代登录、思源同步或 AI 功能。

## 状态口径

| 类型 | 筛选 |
| --- | --- |
| 旅程 | 全部、计划中、已完成、已归档 |
| 照片 | 全部、待补精确位置、待补日期、已定位、只有地点名称、待收录上传、已隐藏 |
| 旅程到访 | 全部、待补城市、已归属 |
| 图文日记 | 全部、草稿、已记录 |

照片「待补精确位置」包含没有地点和只有名称／城市的可见照片；「已定位」要求已确认坐标。隐藏照片仍在全部台账中，但不计入待补日期和位置任务；整理弹窗只读，避免保存时意外重新展示。

日期、地点名称与备注优先取独立照片信息；尚无独立信息的旧照片沿用日记日期、关联地点及城市、原图片说明。独立记录明确清空的字段不会再被旧日记补回。只有 EXIF 建议、没有已确认日期的上传仍算待补日期。未关联日记且未收录为照片回忆的上传列为「待收录上传」，保存后正式进入照片回忆。

旧照片首次独立整理会保留日记关联和地点所在城市；不会因为只改日期／备注而丢失城市归类。当前关联旅程已删除时，仍保留日记自身可用的名称快照，不猜测原城市或精确位置。

## API 与实现

| 接口 | 行为 |
| --- | --- |
| `GET /api/v1/admin/catalog/:resource?status=&q=&page=` | 状态在对应资源内校验，筛选计数与分页结果一致；不支持的组合返回 400 |
| `GET /api/v1/admin/photos/:id` | 照片有效元数据、版本、关联日记与原图日期／位置建议；不返回日记正文或任意 EXIF 字段 |
| `GET /api/v1/admin/photos/:id/content?variant=thumb\|preview` | 管理员受控衍生图，无匿名访问；不接受 original 或任意文件路径 |
| `PUT /api/v1/admin/photos/:id` | 单张照片版本化保存，body 为照片字段与幂等 ID；路径和 body 的媒体 ID 必须相同 |

所有新增接口沿用 owner 权限；普通编辑 403、匿名 401，写请求继续检查 Origin／CSRF。管理员可以整理台账所属账号的照片，审计记录实际执行管理员；普通编辑的媒体所有权接口不改变，其他用户不能借后台 URL 越权。

`backend/src/admin-photos.ts` 统一计算照片有效元数据、筛选和待整理数量；`admin/src/components/PhotoInspector.vue` 负责预览、编辑和名称搜索。高德复用现有 SDK／服务端安全代理，不引入新地图或 UI 依赖。

照片保存复用 `photoService.save`，为管理员操作隔离幂等 scope，并在同一事务写 `photo.update` 审计。版本冲突不覆盖服务器；隐藏／已移除媒体不能通过后台保存重新启用。相同请求重放只保存和记录一次审计。

前端服务端确认成功后才关闭弹窗。网络或服务器异常后保留原请求及幂等 ID，锁定字段并支持原样重试，避免提交已成功但响应丢失后重复写入。冲突保留正在编辑的字段；「重新读取」明确确认放弃修改后获取服务器版本。关闭或刷新有未保存信息时给出离开提示；当前不提供跨浏览器或跨重启的后台照片草稿恢复。

本轮不新增表或字段，不执行数据库结构迁移。
