# M4.1 可撤销行程分享

更新：2026-10-22。状态：本机实现、隔离验证与现有预览升级完成；M4.2 的 HTTPS、正式静态部署与整体恢复另行推进。

## 设计

- 本节点为「持链接可见」的行程快照，不建立公开目录。本人从行程入口预览、确认创建；默认只包含所选计划／实际层的标题、目的地、日期标题、地区、地点名称与交通安排。
- 默认排除结构化日期／时间、备注、住宿字段、精确坐标、路径几何／GPX、到访记录、所有日记与照片。可单独加入日期、备注、所选的已写完日记以及这些日记的预览照片。文字中的个人信息需本人在预览中检查，不自动语义脱敏；行程地点本身可能含住宿名称。
- 分享前返回独立访客 DTO 和输入指纹，创建时重新核对当前来源，变更要求重新预览。快照不随编辑更新；重新分享创建新链接，旧链接可撤销。计划和实际明确区分，实际也不冒充 GPS 实录。
- 有效期 1／7／30 天，默认 7 天；随时撤销。每人最多 20 条有效链接、滚动 24 小时 20 条创建、200 条保留记录；快照最多 1MiB、20 篇日记和 100 张照片。
- 访客页不需要登录，不加载编辑或管理数据、不提供原图／源文件／地图密钥。使用独立图片槽位，只提供去 EXIF 的 WebP 预览；日记删除、转草稿或改关联后，相关日记停止展示；照片移除／删除后停止提供。快照文字被修改时仍保持旧快照，需撤销旧链接来停止旧版本访问。

## 链接与服务边界

使用 `/s/<分享ID>#<凭证>`。凭证仅在 fragment 中，不发送到网页 URL 或图片查询字符串；访客 API 通过 Authorization Bearer 读取，浏览器请求不携带本人会话。凭证通过独立服务器密钥 HMAC 派生，数据库只保存摘要，重试账本只保存分享 ID；本人可重新复制有效链接。密钥只存 `.env`，稳定保管，轮换会使旧链接失效。

访客响应禁止缓存和索引，无效／过期／撤销／停用账号统一返回不可访问。图片每次请求检查同一链接、所选日记当前状态及照片绑定；撤销不能追回访客已经下载或截图的内容。分享不会给供应商几何增加展示许可，本节点不发布几何。

当前网站仍为 HTTP 预览，HTTPS 与对外正式上线属于 M4.2；不在本节点修改用户的 OpenResty 配置，不自动创建正式分享内容。

## 实现接口与存储

全部业务接口位于 `/api/v1`。本人接口要求已有会话，写操作继续校验 Origin 和 CSRF。

| 接口 | 用途 |
| --- | --- |
| `GET /journeys/:id/share-options` | 可选已写完日记与服务能力，归属校验 |
| `POST /journeys/:id/share-preview` | 根据当前保存内容裁剪预览，不写分享表 |
| `POST /journeys/:id/shares` | 指纹、确认、范围与幂等校验后创建 |
| `GET /journeys/:id/shares` | 本人链接列表、状态、期限与有效链接重新复制 |
| `POST /shares/:id/revoke` | 幂等撤销，只允许本人操作 |
| `GET /public/shares/:id` | Bearer 凭证下的专用快照，匿名可访问 |
| `GET /public/shares/:id/photos/:key` | 同一凭证下的所选 WebP 预览图；不接受原图参数 |

`share_links` 保存 owner／journey 外键、凭证摘要、访客字段快照、私有图文绑定、创建／到期／撤销时间。访客只获得快照，私有绑定不返回。图片使用 `p1` 等单次分享内槽位，不暴露媒体 ID 或原文件名。字段白名单不含 owner、业务 ID、路径来源、复制链、位置、媒体文件名、内部 URL、原图或地图运行时配置。

事务先锁定当前用户，跟现有行程／日记写入保持同一串行边界，核对源版本、照片及范围指纹再写入；幂等账本仅保存分享 ID。修改选择会使页面预览失效；服务端也会在来源变化时拒绝旧预览。快照不含几何，不改变原始行程／日记的 private 状态，不开放公开注册。

`SHARE_LINK_SECRET` 配置为独立的 32 随机字节（64 位小写十六进制），不可复用数据库或本人密码。未配置时可预览，但创建／访客读取关闭。有效链接可以重新派生以便复制；轮换后旧摘要不再匹配，不能恢复为有效链接，不计入有效配额。配置和数据库需一起安全备份；若重新使用旧密钥及旧数据库快照，旧链接的访问状态也可能恢复，恢复方案需另行验证。

`npm run share:cleanup` 手动清理已到期或撤销超过 30 天的分享历史；不删除行程、日记和图片。本节点没有定时清理。删除／转草稿／取消关联只阻止之后的新读取，正在传输、已经展示或已下载的内容无法追回；日记重新满足选择条件时可再次展示原快照，要永久停止使用撤销链接。

访客路由在加载时绕过私人会话读取，正文按纯文本渲染，不执行输入 HTML。照片接近视口才用 Bearer 请求并创建本机 Blob URL；卸载时取消请求并释放 URL。页面提供刷新以重新校验链接，失效后不继续展示内容；不能控制接收者自行保存的副本。页面加入 `noindex,nofollow,nosnippet`，API 返回 `no-store`／`no-referrer`，没有公开索引、访问统计或第三方底图请求。
