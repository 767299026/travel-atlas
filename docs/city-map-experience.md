# 城市 2D 足迹地图的信息层次与浏览体验

日期：2026-10-26。用户确认“先修改看看”后已实施第一版：紧凑城市页、旅程卡归并、按需显示路线、点选摘要与浏览位置恢复。地点聚合与重叠路线选择仍为后续增强。只修改本仓库 Vue 使用端；OpenDesign 原型、业务数据与数据库结构不变。验证与发布记录见文末。

## 改版前的问题与实际依据

用户反馈：放大进入城市 2D 地图后，回忆路段和地标一起展示，挤占屏幕，显得混乱。

读取当前 `CityFootprintMap.vue`、`Footprints.vue`、`AtlasRouteCards.vue` 及样式，使用真实 HTTPS API 与高德矢量地图截图核对。当前武汉样本为 **17 条到访、14 段路径、2 个关联旅程**，不是 14 次独立旅行。

改版前的问题包括：

- 城市进入时默认同时开启地点与路径，所有路径较粗；路径选中仅将其余路径降到约 22% 不透明度，其他旅程的地标仍保留。用户仍需从多套点线中识别当前内容。
- 底部卡片按每段连接生成，将两次旅程展开成 14 张路段卡片。细分连接适合路径编辑，不适合回忆首页的第一层浏览。
- 同一抽屉混排路段、记录操作、全部地点、相关旅程、日记与计划。点击地图地点会打开整份抽屉，再滚动到记录；点击路径也会展开卡片区。一次轻点会改变大半个页面。
- 图层复选框、来源说明，以及点击提示／新增区分别占据固定行。真实地图面积持续受挤压；仅修改标注避让不能解决这些固定空间成本。
- 现有名称避让主要在自有标签之间工作，没有完整解决自有标记与底图 POI、路线及面板之间的竞争。

393×775 模拟视口的实际尺寸：

| 区域 | 改版前高度 |
| --- | ---: |
| 城市地图组件（含图层栏） | 419px |
| 真正的高德地图 | **352px** |
| 常驻图层与来源栏 | 67px |
| 地图下方点击提示／新增区 | 64px |
| 抽屉收起 | 56px |
| 点击地点后的完整抽屉 | 约 481px，覆盖地图 |

这里 67px 与 64px 合计 131px。若不再单独占据布局行，同一视口可给地图增加相应空间；最终高度需在实际改版中验证，不能把估算当成交付结果。

## 当前浏览结构

核心：**城市概览 → 选中一次旅程或一个地点 → 主动查看完整回忆**。缩放负责空间密度，点选负责内容聚焦；缩放进入 2D 本身不展开列表，也不自动选中最近旅程。

| 浏览状态 | 地图内容 | 底部内容 |
| --- | --- | --- |
| 刚进入城市 | 紧凑到访点，默认不铺开全部线路和名称；聚合待后续 | 保留现有约 56px 单行入口 |
| 选中一次旅程 | 仅突出当前旅程在该城的已存路线，显示起终点与少量相关地点；其他旅程覆盖物隐藏 | 一张约 100～128px 的摘要，含日期、标题、来源和“查看回忆” |
| 选中一个地点 | 地点高亮与名称，其他标记退后；不自动铺开其他路线 | 当前地点摘要，可打开相关旅程／日记；不自动展开长列表 |
| 主动展开回忆 | 保留当前选中对象 | 按旅程或地点浏览；正文进入已有详情页，返回恢复地图上下文 |

“显示全部路线”作为图层面板里的主动选项保留，满足查漏和整体回看；不是默认状态。显示时用细线、低对比度，地点文字仍按密度限制。取消选中回到概览；点击地图空白不强制飞回城市中心，居中按钮才执行重新适配。

## 第一版地图空间与控件

1. 城市级采用紧凑顶栏：返回地区图、城市名、原有时光／寻找入口。品牌与中国／世界切换留在上层图鉴，避免城市页继续占多行。保留年份上下文，返回上层也不清空年份。
2. 地图优先填满剩余空间。取消常驻图层栏和独立的点击提示行；新增入口移入现有工具入口或回忆面板，避免再增加底部行。393×775 的真实地图实测为 **597px**（改版前 352px）；选中后保留 **533px** 地图与 **120px** 摘要。320×640 的概览地图为 462px，不硬设固定高度。
3. 沿用右上角折叠工具风格，展开后再提供地图内容设置；选项保持少量，不增加一整排常驻筛选按钮。
4. 来源说明随可见路线出现：例如摘要里一枚“路网参考”或“手工补绘”标记，详细来源按需打开。不在地图下方长期重复多行说明；保留高德原生署名与标识。
5. 预览卡与完整列表分开。手机完整列表当前展开至约 45% 工作区高度，最大 380px；393×775 实测约 294px。阅读正文进入已有详情页。点地图标记只进入摘要，完整展开必须由用户主动触发。

## 路线和地点的呈现规则

### 旅程是主卡片，路段是内部细节

- 当前 14 张路段卡先归为 2 张旅程卡，完整呈现一程的轮廓与标题。点击卡片显示该程所有已存分段，保留真实断点，不补直线。未保存几何的旅程也应在回忆列表可达，不因缺路径而消失。
- 展开一程后再看日期、地点与分段，分段的来源／核对／编辑保留在现有路线详情。多日旅程可再分日；当前 DTO 没有 dayId，不能据此声称已能准确分日。
- 不把分段数当旅行次数，不把导入参考路径里程合计成个人实录运动里程。部分几何、混合来源或截断响应需保持明确含义。
- 默认回忆列表展示旅程；“地点”作为展开面板内的另一个视图，避免路段、地点、日记和计划同时铺开。行程计划仍留在规划功能，不混入已走过图层。

### 地点名称已分级；聚合与重叠选择待后续

- 当前城市远景使用小点，不附全量名称；放大后按空间预算显示，窄屏最多约 4 个、宽屏约 7 个，选中地点优先。密集点的聚合／解聚合尚未加入第一版。
- 后续同一区域或同坐标有多条记录时显示记录数量；聚合数字代表“条到访记录”，不能在缺少规范地点 ID 的情况下当成“几个不同景点”。点聚合点先放大／展示记录选择，不能随机打开其中一条。
- 窄屏名称展示可先以 3～5 个作为测试预算，而不是固定比例尺一到便显示全部。优先显示当前选中地点、当前旅程起终点；位置不够时保留可点击的圆点。
- 弱化普通商业 POI，保留道路、水系和区县等空间参照。关闭所有地名会让地图失去方向，不能作为降噪捷径。自有标注仍要避让控件、原生署名与当前摘要。
- 当前路线点击已按旅程处理。多条路线重合时的“选择一次经过”列表待后续；第一版可从旅程卡准确选择。

## 交互与实现边界

- 暂不更换地图 SDK。高德已有 [MarkerCluster](https://developer.amap.com/api/maps-javascript-api/reference/amap-marker/markercluster) 和 [LabelsLayer／LabelMarker](https://developer.amap.com/api/maps-javascript-api/guide/amap-massmarker/label-marker)，支持聚合与标注避让。本项目问题优先通过内容选择、空间布局与图层规则解决；插件与现有 DOM 键盘交互的适配仍需验证。
- 当前 API 的 points／paths 已有 journeyId，足以先做按旅程分组和选中联动。第一步不需要改 MySQL 表，也不修改真实路径、到访状态或日期。
- 仅转换和渲染当前可见内容。当前接口仍一次返回整城数据，减少覆盖物并不自动减少网络载荷；若数据量增长，再拆分概览摘要与选中旅程几何的请求。
- 将选择对象明确为“无／旅程／地点”，面板明确为“收起／摘要／浏览”，避免 selectedPath、focusedRecord、expanded 的多种组合互相抢显示。路径分段选择仍可作为编辑页内部能力。
- 相机适配为摘要和工具预留实际 padding；选择一程时平滑移动一次。拖动地图不重新适配、不退出所选旅程；关闭摘要不重置年份与相机。减少动态效果偏好继续有效。
- 点聚合点、名称或路线的视觉对象可以很小，实际触控目标需充足；聚合／避让应按屏幕像素距离处理，不仅按坐标距离。不要在每个拖动事件中销毁重建全部覆盖物或重复计算整城坐标。
- 桌面沿用侧栏，但采用同一内容层级：默认旅程摘要列表，选中对象详情替换侧栏内容，不继续堆叠全量地标、路段和图文。

第一版已验证高德自动兼容路径。矢量模式可显示浅色主题；自动兼容的栅格模式仍保留标准彩色底图与部分 POI，不能保证同等降噪，但新的内容分层与摘要交互均可用。应用不强制用户设备使用 WebGL。

## 后续增强与验收范围

第一版已完成空间、旅程级卡片、默认概览与点选摘要，名称按缩放与预算显示。密集地点聚合、重叠路线选择和更大数据量的按需请求继续后置；每步仍需两轮实图自审。

验收场景至少包括：

- 同城两次旅程、远近两组地点、同地点多次记录、重叠线路；旅程很多时不增加默认地图文字和卡片占位。
- 进入城市不展开面板；点击一点或一程只出现对应摘要；完整回忆需再次主动打开；取消后恢复概览而非跳回全国。
- 当前筛选年、城市与相机可恢复；数据无几何、无日期、未定位、截断或全空时仍可理解和访问。
- 393×775、320×640、横屏与桌面实际查看；检查真正的地图高度、摘要遮挡、版权署名、聚合点触控、滚轮／双指手势及快速切换。
- 真实高德矢量与自动兼容路径分别查看；浏览器手机模拟不等于小米真机体验或高刷新率验收。

## 第一版实现与验证（2026-10-26）

- `CityMemoryPanel` 将收起／摘要／完整浏览分开：手机收起一行、摘要 120px、完整面板约 45% 工作区；桌面用独立侧栏替换所选对象详情，不混排所有内容。
- `AtlasJourneyCards` 按 journeyId 归并，每张卡绘制该旅程兼容坐标系的独立分段；缺几何、缺日期、混合来源与混合坐标系均有明确处理。未保存几何的旅程也保留入口。
- 城市概览仅转换和绘制地点；选择旅程时才绘制其在该城的路径与地点，选择一点时只突出这一点。图层面板仍可主动开启全部路径；设置不再占布局行。普通 POI 要素关闭，道路、水系与空间参照保留。
- 原始几何与库中来源不变；图层计数在载入时清零并使用异步完成状态。转换分批排队，切换后停止继续提交旧任务，避免高德 QPS 限制与旧覆盖物回填。
- 城市、年份、选择对象、面板与 GCJ-02 视角以账号为键保存在当前浏览器标签页的 sessionStorage；只存浏览状态，不存整城几何。进入行程后返回／刷新可恢复；存储不可用时不影响正常浏览。它不属于路线导出或到访数据。
- 第一轮在真实手机尺寸查看概览、两张旅程卡、旅程／地点摘要与图层设置。确认地图扩大；发现 SDK 可能将同一次标记点击再传到底图，导致立即取消选中，改为以同一指针手势识别覆盖物事件；补齐关闭摘要、查看回忆与键盘焦点。
- 第二轮复看 320×640、393×775、844×393 和 1280×900。发现旧原型 body 外边留白使横屏／桌面导航超出视口，城市级单独清除并新增视口边界检查。另修正记录移除后的选中状态，核对无日期／无路径、年份、API 失败重试与浏览位置恢复。

截图、计数、只读业务指纹与结果保存在被忽略的 `data/city-ux-review-20261026/`；正式业务表未作为测试夹具。所有浏览器夹具使用随机隔离前缀与专用媒体目录并顺序清理。真实高德矢量截图仅在测试上下文开启软件 WebGL，应用不强制用户渲染模式。实际小米真机与触控手感仍需用户复看。
