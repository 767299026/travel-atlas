## 地图实现

全国和省级保留图鉴式 SVG。名称来自已有地区数据，密集区域避免文字覆盖，放大后显示更多；悬停提示、键盘名称和列表入口保留。滚轮以光标位置为中心缩放，范围 1–8 倍；拖动使用 SVG 实际坐标转换，避免宽屏留白造成位移不一致。

目录内国内城市（含直辖市）进入 `CityFootprintMap`：使用高德 JSAPI 的 2D 在线地图与官方地名；地区目录几何和未经确认的代表点坐标不叠在高德上。城市初始定位由高德 `setCity(adcode)` 完成；境外或手填的无编码城市仍在图鉴与列表查看。

SDK 初始化仅按需执行，与原路线编辑页共享加载器。采用同源安全代理，安全码仍只在服务端。真实联调中 SDK 的 `scrollWheel` 开关未令测试浏览器缩放，改由地图容器显式处理 `wheel`，调用公开缩放／容器坐标接口维持光标锚点；原生 SDK 滚轮关闭，避免重复。双指缩放仍交给 SDK。滚轮有 100ms 节流，地图控制面板不触发缩放。

图层支持地点／路径独立开关、查看全部、放大／缩小、点标记打开对应到访、线段进入实际旅程。精确圆点与文字标签分开，标签会在缩放／平移后避让，空间不足时保留圆点和键盘／列表入口；不挪动实际点坐标。屏幕尺寸改变后重新适配足迹范围，避免从桌面切到手机时标记被裁切。桌面完整侧栏、手机折叠抽屉；城市标题有浅色底板。

新增／删除城市记录后同时刷新市级图层，不要求手动刷新页面。失败清除旧图层，保留列表和重试；未定位、截断、显示抽样及未核对路径分别说明。

高德公开接口依据（2026-10-23 核对）：[Map 参考](https://developer.amap.com/api/maps-javascript-api/reference/amap-map/map)、[JSAPI 2.0 参考](https://a.amap.com/jsapi/static/doc/index.html)、[设置行政区示例](https://lbs.amap.com/demo/javascript-api-v2/example/map/set-center-according-to-map-name/)。本轮只核对具体接口及实际显示，不改变此前关于账号、长期保存与地图内容使用范围的待验结论。

## 足迹来源与接口

`GET /api/v1/atlas/cities/:code?year=all|unknown|YYYY` 需登录、有效国内市级目录编码；所有数据按 owner 限制。

- 精确点取确认到访时保存的 `visits.location` 快照，保留 WGS84／GCJ-02／BD-09 来源。地图显示转换通过官方 SDK，传入数组复制，不改写数据库和原文件。
- 计划、心愿不变成精确足迹；只有城市归属、没有坐标的补记列入“未定位”，不放到城市中心冒充实录。
- 线段仅取本人的 actual 路线、两端均已确认到访且属于所选城市／年份、当前有效且端点位置与快照一致的已存几何；计划、过期、断点、跨城连接不补线。
- 显示说明区分手工补绘／导入参考／路网规划，未核对路径明确提示；不把几何当 GPS 实录或通行承诺。
- 最多显示 500 个到访点、20 个路径资产；候选最多检查 61 条。密集路径每资产显示至多 300 点，保留独立分段和端点，源资产不修改；超出范围提示进入具体旅程查看。
- 公开分享 DTO 没有新增精确足迹，城市接口仍为本人会话接口。本轮无数据库结构迁移。

## 模拟数据与操作

用户明确授权本轮实际插入。先用随机测试表前缀验证，再于北京时间 **00:56** 生成 SQL 备份（27,367 字节、600），随后通过现有业务服务建立：

| 内容 | 数量与范围 |
| --- | --- |
| 已完成旅程 | 3 条：江城两岸、西湖与绍兴三日、黄山一日 |
| 行程到访 | 14 条，其中 1 条待归属、1 条已归属但未定位 |
| 城市补记 | 成都 2024、南京日期待补充，共 2 条 |
| 城市心愿 | 昆明 1 条，不计到访 |
| 足迹统计 | 6 座城市、5 个省级地区、全部到访 16 条；地图中国区域已归属 15 条 |
| 日记与图片 | 3 篇、3 张自行生成的演示插画，走私有上传／缩略图流程 |
| 实际路径 | 7 条手工模拟补绘，跨日／跨城缺口不连线，无公开分享 |

标题和备注标「演示」，图片含 DEMO 及非旅行摄影说明。模拟地点与点串只用于页面显示；既非现场 GPS，也不是可导航路线。**这些数据目前保留在本人库中，并计入当前统计。**没有导入原型摄影或真实私人笔记。

```bash
npm run demo -- status
npm run demo -- seed
npm run demo -- cleanup
```

清单在忽略的 `data/demo/map-review-v1.json`（600），逐步保存已生成对象和操作标识；重复 seed 不重复建库内内容。本次已实际重复执行一次，保持 3 个旅程。首次写入／清理前自动 SQL 备份，种子操作有独立锁。

cleanup 仅操作清单中的 ID，先比较内容指纹并在本人写锁下再次核对；演示被编辑、出现新关联／分享或清单不完整时停止，保留用户修改。清理过程隔离验证过：保留无关真实行程、修改过的演示阻止删除、正常清单清除行程／日记／媒体及演示操作缓存。正式演示当前未清理，便于用户查看；已清理清单需归档后才可重新生成。

图片移除是 SQL 事务后的文件操作，整体机器崩溃／恢复仍未演练，不把此工具等同数据库和媒体整体恢复方案。

3. 原型页面 **16 组**、原路线地图 **10 组**针对最终地图建设期间构建回归通过；其他前期回归未在本轮全部重跑，不能把历史累计数当本轮运行次数。
4. 真实 HTTPS 域名 **8 组**：本人模拟统计、全国滚轮、真实高德道路／地名与点线、真实滚轮／查看全部、手机／抽屉、城市日记图片、已完成旅程、WGS84 显示转换；无 pageerror。使用本机域名解析到服务器，未检验外网 DNS／真实手机网络。

API／主站仍由现有 screen 托管，新构建经过暂存与健康检查后切换，旧构建和旧哈希资源保留在 `data/releases/`；管理端和区域路由进程未替换。没有修改原 OpenDesign 或现有 OpenResty 配置。
