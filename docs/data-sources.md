## 推荐接入方式

通过思源公开 API 读取，首版手动触发同步，后续定时增量同步。保存 notebook/document/block ID、标题、路径、源更新时间、抓取时间、内容哈希和原始正文。保留关联块引用与附件来源。

同步只覆盖源内容快照，不覆盖用户修订字段。思源删除或移动文档时应标记待处理，不直接删除已关联行程和日记。

原始资料默认私有；公开发布以用户确认的行程与日记为单位。抽样笔记包含国家地理等参考图片，笔记自己的图片规则也限定为个人资料整理；不要自动批量发布这些参考图。公开照片需另设来源与发布状态。

密钥从服务器 `.env` 获取，采用 Authorization Token 鉴权，不写入前端代码、日志或文档。
