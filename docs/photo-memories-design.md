# 回忆：照片墙与照片地图

日期：2026-10-27。状态：用户已授权落地新版照片回忆；已迁入 Vue，并接通私有照片 API、MySQL 与真实高德地图。OpenDesign 原型保持只读。实施、验证和当前交付边界见文末。

## 已确认的方向

- 用户没有持续写日记的习惯，“回忆”不再以日记文章列表和阅读页为主要入口。
- 列表按月份、地点整理照片，支持一两行简短备注，希望有翻阅老照片、想起拍摄地点的氛围。
- 地图展示实际去过的地方，放大进入城市 2D 后，在照片拍摄地点高亮标点。
- 照片位置来自原图 EXIF 建议或手动搜索／地图选点；建议必须确认后才上图。当前已完成 JPEG 元数据与地图联调，更多相机格式和真实手机相册仍需补验。
- 本轮实施回忆板块；旅程调整另行讨论，首页保持现有方向。

## 当前设计与待验证边界

当前原型默认打开照片列表，月份为一级、地点为二级分组；备注可选，单张或同组照片均不要求文章标题与长正文。老照片氛围来自留白、纸边和排版，照片保留原色。具体样式仍可随用户的原型评审继续调整。

照片地图与首页足迹在视觉上保持一致，但内容侧重照片与拍摄地。最新原型远景采用 D「地点短签」、城市级采用 C「照片滴形」，标记本身不显示数量；照片张数留在选中摘要和照片组中，不能当作旅行次数。同地点多张照片合并，选点后显示小摘要，再主动打开照片浏览。此规则更新了最初提示词中在聚合点显示数量的建议。

待补充拍摄时间／地点的照片仍进入列表；地图仅展示已确认拍摄位置的照片。不得用上传时设备所在位置替代拍摄地点，也不得把照片顺序推导为实际轨迹。已确认照片定位与行程到访独立；坐标表示、显示转换和确认流程的实现见文末。

## 新版原型吸收记录

通过项目 API 定位「迹屿 足迹地图设计」，读取 `memories.html`、`current/memories.js`、`current/memories-data.js`、`current/styles/memories.css` 及 `DESIGN.md`。新版页面标题为“沿途的片刻”，独立加载回忆模块；示例含 9 张照片、三个已知月份及缺失日期／地点状态。

| 部分 | 当前原型呈现 | 后续对齐重点 |
| --- | --- | --- |
| 照片墙 | 月份 → 地点 → 照片，手机两列、横图可跨列，桌面扩列；白纸边、轻阴影、原始比例与原色 | 延续相册阅读感；单张备注、整组备注分开，不要求文章标题 |
| 大图浏览 | 完整比例、同组前后翻看、单张／整组短备注；按需编辑、“在地图上看” | 关闭恢复原有列表位置或地图视角，保持照片优先 |
| 远景地图 | 地点短签；屏幕上邻近的城市可合并为一个签，选中后展示代表图与照片数，多城先放大 | 保持小尺寸标记与至少 44px 的透明点击范围；数量不常驻标记 |
| 城市地图 | 照片滴形标点，轻描边与选中反馈；点后先看小摘要，再翻看该组 | 复用已有真实地图能力时迁移标记外观，不照搬原型的底图与交互实现 |
| 添加照片 | 多选 → 日期／拍摄地点 → 可选单张和整组备注，可批量应用当前日期／地点，可存草稿 | 照片独立存在，不强制关联行程或日记 |
| 补充位置 | 示例建议待确认、无位置可跳过、已知地点搜索、手填名称待定位、地图选点主动确认 | 地点名称与确认坐标分开，上传位置不能冒充拍摄位置 |
| 筛选与空状态 | 年份／地点弹层，支持时间／地点待补充；首次使用独立空状态 | 缺失信息的照片保留，筛选无结果可恢复 |

原型采用独立 IndexedDB `atlas-photo-memories-preview-v1`，没有后端上传、EXIF 解析、系统定位或真实地理搜索。`?empty=1` 是独立空状态演示；日期与位置建议为示例资料。JPG／PNG／WebP、单批 12 张、单张 8MB 是原型当前限制，尚未确认为正式上传策略。原日记、行程数据与此相册演示分开。

吸收原型时已标记：照片资料与媒体文件、来源确认状态、短备注及旧日记兼容必须单独建模，不能照搬 IndexedDB 与 data URL。原型城市图仍是本地行政区参考图；正式 Vue 页面已接回高德街道底图和官方坐标转换，具体实现与未覆盖格式／真机边界见文末。

## 初版 OpenDesign 提示词归档

以下是本轮最初提示词，保留讨论过程；标记外观与数量呈现以后来的原型吸收记录为准。

```text
请基于当前「迹屿 Travel Atlas」项目，只重新设计底部“回忆”板块，先出一版可交互样式供我预览。当前工程已同步网页样式，请以现有 HTML 和 current/styles/ 为基础，保持暖纸白、森林绿、统一线性图标及底部四个入口，首页和旅程本轮不改。

核心体验：我没有写长篇日记的习惯。回忆应该围绕“照片、拍摄地点、一两句备注”展开，让人翻到照片时想起“啊，这是在那个地方拍的”。主入口改成照片回忆，不再沿用日记文章卡片、文章标题和长正文的组织方式。

1. 两种浏览模式
顶部保留简洁的“列表／地图”切换，默认列表。年份、地点筛选用紧凑按钮按需展开，添加照片用一个清晰入口，不用大型搜索栏或统计卡占据空间。切换模式保留筛选；关闭照片后回到原来的列表位置或地图视角。

2. 列表：按月份和地点整理的照片墙
月份作为一级分组，例如“2026 年 10 月”；月份下按地点分组，例如“武汉 · 东湖”“武汉 · 江汉路”。以照片占据主要空间，地点名、可选拍摄日期和一两行短备注作为轻量辅助。备注可以对应一张照片，也可以描述同一组照片；不强迫填写标题或正文，不写备注也成立。
手机以两列照片为主，允许少量横向大图与横竖照片组合；桌面自然扩展列数。用细纸边、轻微阴影、适度留白和小号日期营造翻旧相册的感觉，延续现有干净克制的风格。保留照片原色，不统一套浓重泛黄滤镜，不堆叠胶带、邮戳、歪斜相框等装饰。
示例短句如“东湖边，坐着吹了很久的风”“走累了，在街口吃了一碗面”。没有日期或地点的照片放在“时间待补充／地点待补充”分组里，仍可正常浏览。

3. 照片查看
点击照片进入以原图为主的大图浏览，保留完整比例，可前后翻看同组照片。地点、拍摄时间和可编辑的短备注轻量呈现，不跳转到文章阅读页。提供明确返回／关闭；已有地点时可以“在地图上看”。文字不遮住照片主体，编辑操作按需出现。

4. 地图：用地点找回照片
沿用首页地图的视觉语言，让地图占主要空间。远景展示有照片的已去地点；放大到城市 2D 视图后，在拍摄位置显示照片小缩略图或统一的照片标记，选中时再高亮。
同地点／密集位置的照片合并为一个标记，数量表示照片张数。点击先显示一张照片、地点和数量的小摘要，再主动进入照片组；保持其他标记克制，不同时铺满名称、照片卡和完整列表。这里不铺行程路线，也不把照片之间连成轨迹。没有确认拍摄位置的照片保留在列表，不随意放到地图上。

5. 添加照片与定位的样式预留
设计轻量的“选择照片 → 确认日期与地点 → 可选短备注”流程，支持一次添加多张照片。只演示三种状态：有拍摄位置建议并等待确认、没有位置待补充、手动搜索地点／地图选点。允许修改、跳过定位和以后补充，不强制关联行程。
照片定位读取是后续待验证能力，本轮只做界面演示，不接真实读取或定位服务，不承诺每张照片都有定位。手动选的是拍摄地点，不是上传时设备的位置；这些技术说明写在设计说明中，不堆进日常浏览界面。

6. 预览与交付
请提供照片墙、照片大图、地图远景、城市 2D 标记、地点照片组摘要、添加照片／补地点以及空状态，使用跨两三个月、多个地点的示例照片，保持各页面内容一致，注明示例摄影来源。
检查 390px、320px 和桌面尺寸，重点看照片比例、分组留白、备注换行、弹层高度、底部导航和返回路径。示例定位、上传与保存仅作原型演示。将更新后的回忆页面加入 prototype-index.html，更新 DESIGN.md，并说明本轮涉及哪些 HTML／CSS。完成后实际预览截图，做两轮自审再交付。
```

### 已实现的页面和持久化

- `/memories` 默认照片墙，月份／地点分组，按原比例排列；手机两列，桌面三至四列。保留纸边、淡阴影和两行短备注。第一轮发现竖图遇到横向跨列图片产生大块空白，手机限制宽幅图片不跨两列，桌面保留宽幅跨列；大图浏览保留完整比例。
- 支持年份、城市和日期／地点待补筛选；单张备注与整组备注分别保存。大图支持同组前后、左右键、触摸滑动、编辑、移除、回到地图。列表滚动位置与页面内地图视角保留，筛选／模式按账号保存在标签页中。
- 独立上传不需要新建日记或绑定行程。每批最多 24 张，支持 JPG／PNG／WebP，单张大小使用后端运行配置；逐张上传，保存支持幂等重试与版本冲突保护。未完成的新增批次保存元数据草稿，按账号隔离，不把原图写进 localStorage；草稿恢复窗口六天，未关联媒体仍按原七天清理策略处理。
- 原图 EXIF `DateTimeOriginal` 提取本地日历日期，不用上传日期替代；GPS 保留 WGS84。缺少或损坏的元数据不阻止添加。已用自生成标准 JPEG EXIF 和无 EXIF PNG 验证；不承诺社交平台压缩图、截图、WebP 或所有手机导出的原图都有可读定位；HEIC 当前不在上传范围。
- 手工地点可只保存名称；搜索／选点使用真实高德 SDK，选的是拍摄地点，不读取当前设备定位。无城市归属的已确认坐标可通过“查看待补充城市的拍摄位置”进入城市图，之后可补充城市。
- 地图全国／省级复用 Leaflet Canvas EPSG:3857 和地区图，已确认拍摄点按城市归并为地点短签。城市使用真实高德 2D，官方转换只作用于显示，不改原始坐标；按屏幕像素归并照片滴形，不显示标记数量文字。点选小摘要再进入照片组，不展示路线或全部文章卡。保留底图的道路／地点文字和图源署名。
- `GET/POST /api/v1/photos` 和 `DELETE /api/v1/photos/:id` 继承登录、CSRF、账号隔离和私有媒体鉴权。新增 `photo_memories`、`photo_group_notes` 两表及媒体 `capture_metadata` 可空字段，总业务表从 19 增至 21。迁移只增表／字段，不批量复制或重写旧日记。
- 原有日记照片只读投影到照片墙，不改原文章、说明和文件；第一次补充照片信息才建立独立覆盖资料。旧日记关联地点仅提供待确认位置建议，不擅自认定 GPS。照片移出相册时，仍被日记使用的文件保留；从日记删除照片时，已独立保存在相册的文件保留。
- `/journals` 保留旧图文日记入口，位于照片墙底部；日记详情和原有行程中的写日记入口继续可用。本轮不新增公开相册或照片分享链接。
