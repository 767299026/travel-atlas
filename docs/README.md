## 当前状态

- 已确认 Vue 3 + Vite + TypeScript、Node.js + TypeScript、本机 MySQL、网站优先及预留安卓打包。
- 本轮交付范围为 Vue 网页，由 Nginx／OpenResty 提供预览和访问；不需要安卓包，电脑与手机通过浏览器使用。
- 行前在线规划、回程图文记录；用户不需要离线地图或依赖持续 GPS 记录。
- 使用端当前为用户标注的 v4，已完成隔离浏览器抽查。高德 JS 地图、服务端安全代理、搜索及少量算路已通；三个山路样本有几何，长坪沟终点偏移约 837m。目标线路正确性、生产域名、地图授权、AI、安卓真机仍待验证；M1 数据库结果见下文。
- 独立管理端已实现首版工作台，设计与范围见 [管理专题](admin-console.md)；OpenDesign 使用端原型未改。
- 社区户外方向已在三个区域取得 OSM 对象（黄山含几何）及一张 OpenHikingMap 瓦片；部分查询曾超时，目标线路完整性、徒步路由及客户端速度仍待验证。
- 黄山简化局部图已找到云谷寺至白鹅岭的连续候选线，约 3.14km，已保存示意与 GPX；不是 GPS 实录或正式路线验收。
- 同一组 OSM 点调用 BRouter 徒步 profile 成功，返回约 3.12km 路径，几何与局部图基本重合；模型高程／耗时与生产规则未验收。
- 已形成路线数据模型与 API v0.1；M1 编辑与 M2 实际记录、到访、私密图文子集已实现，几何与异步候选已在 M3 实现。
- 用户确认继续网页开发后已完成 M0／M1：MySQL 驱动、迁移、9 张业务表与本人账号、Vue 行程编辑及真实保存；先在隔离前缀表验证后迁移业务表。
- M2 已实现计划复制／空实际记录、手动到访、图文编辑阅读、照片上传／说明／排序／删除、草稿冲突保护和独立管理端。21 项后端测试、12 组 M2 浏览器与 10 组 M1 回归通过；真实手机相册尚待补验。
- Fastify／TypeBox、Drizzle／mysql2 已用于 M1–M2；图片采用本机私有存储与 Sharp。地图服务、对象存储及 AI 仍待验证。
- M2 迁移前已完成 SQL 备份；M2 时为 14 张业务表和账本，保留本人账号，未导入演示内容，隔离表已清理。M2 时 API／主站／管理端使用三个 screen 会话，管理端回环端口 5179；整体恢复与自动备份尚未验收。
- 已复用 OpenDesign v4 的 CSS、SVG 图标与页面结构，在本仓库迁移成 Vue；原型工程保持只读。用户已配置域名预览，前后端按要求使用 screen；正式上线验收仍待后续阶段。
- M3.1 已实现独立地图页、高德按需加载／选点／官方显示转换、手工分段几何、GPX 原件与预览、核对／保护／过期及受控导出；累计 32 项后端、32 组浏览器通过，另完成真实高德与域名上下文检查。M3.1 时为 15 张业务表与账本；M3.2 当前结果见下一条，授权／网络／真机边界见 M3 专题。

## 状态与维护口径

| 状态 | 定义 |
| --- | --- |
| 已确认 | 用户明确接受的目标、边界或选择 |
| 建议初选 | 有依据的建议，尚待最终确认或验证 |
| 待验证 | 需要账号、样本、授权或实测才能决定 |
| 已验证 | 有日期、环境和结果，只覆盖所注明范围 |
| 后置 | 保留扩展路径，不作为当前首版必需项 |
