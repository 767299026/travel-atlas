# 城市地图聚合与重叠选择

2026-10-26，用户确认继续城市地图第二阶段。第一版布局与旅程归并见 [城市地图体验](city-map-experience.md)。本轮继续使用高德，复用既有 Marker／Polyline，没有新增 npm 依赖、数据库迁移或业务数据写入。

## 已实现的交互

- 城市远景将屏幕上相近的到访归为数字点；数字表示**到访记录条数**，不是不同景点数、旅程数或 GPS 采样数。每条记录和原始位置保留。
- 点击相近地点的聚合点，平滑居中并放大，随缩放结束逐渐解聚合。空间预算限制单次放大幅度，最高不超过地图 20 级。
- 相同／极接近位置（显示坐标约 5m 范围）的重复记录直接显示候选；点击放大一次后仍归为同一组，或地图已到缩放上限时，也显示候选，避免要求用户反复放大。候选给出地点、真实记录日期和所属旅程，日期缺失显示待补充。
- “显示全部路线”打开后，点击重合线路会先选择旅程。候选按 journeyId 去重，同一旅程的多个片段不重复列出；只有一程命中时直接进入原有摘要。
- 候选浮层不撑开整份回忆抽屉，不挤占固定布局行；最大高度受地图空间限制，长列表内部滚动，地点名最多两行，日期／旅程保留紧凑上下文。滚动候选不会缩放地图。
- Escape／关闭只收起候选并恢复可用触发点的键盘焦点；选择后仍进入已有的小摘要。年份、城市或数据更新会丢弃旧候选；旧覆盖物的迟到点击不能恢复上一版选择。

## 聚合与命中规则

`frontend/src/maps/cityPicking.ts` 提供纯函数，`CityFootprintMap` 负责实际 SDK 交互，`CityMapChoices` 负责候选呈现。

1. 先使用原有官方转换，将显示所需的 WGS84／BD09 位置转换为高德显示坐标。聚合仅作用于显示层，不回写或导出这些坐标。
2. 按实际投影像素距离约 52px 归组，保留 44px 点击目标。稳定排序与固定代表锚点避免拖动时聚合点来回漂移；不使用无限传递的近邻链，避免整条长路被合成一个点。
3. 聚合在缩放／移动结束、SDK 投影更新后刷新；普通拖动只让 SDK 移动既有覆盖物，不逐帧销毁重建，不重新请求整城坐标转换。视野适配仍使用原始全部点，不能只按聚合锚点截掉边缘记录。
4. 点击线路时，在已显示的分段几何上做约 14px 命中判断，提供更宽的触控容错。不同 part 之间保持断开，不在缺口中生成可点击假线。
5. 数字点优先处理记录选择；线路命中只从当前显示的路线中产生候选，不检索未显示／其他年份／其他用户的路径。

参考核查：[高德 MarkerCluster](https://developer.amap.com/api/maps-javascript-api/reference/amap-marker/markercluster)、[高德覆盖物 API](https://a.amap.com/jsapi/static/doc/index.html)，2026-10-26。采用距离聚合、点击展开的交互原则；本轮显示层沿用既有 Marker，原始几何、来源、缺口和里程均不变。

## 验证与两轮自审

纯函数测试覆盖稳定归组、跨网格邻近点、长链不整体折叠、重复坐标记录、放大后的分离、不同旅程命中去重、断段缺口与触控容错。

```bash
npm run test:browser:city-picking
# 配置 PLAYWRIGHT_MODULE／FRONTEND_TEST_DIST 后可运行真实 SDK 与隔离数据检查：
```
